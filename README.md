# Trvely Convenios · Coopercar

Landing comercial para el convenio de viajes Caribe 2027 entre Trvely y Coopercar.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm test
```

La tarifa final, las categorías de habitación y sus reglas permanecen marcadas como **en validación** hasta incorporar la respuesta del análisis tarifario 2026–2027.
